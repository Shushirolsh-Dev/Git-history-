Homebrew tap for Teal VPN on Mac: brew install --cask tealvpn/tap/teal-vpn

## README overview

Install Teal VPN on a Mac (macOS 13 Ventura or newer, Apple silicon and Intel) with Homebrew:

Update: `brew upgrade --cask teal-vpn`. Remove: `brew uninstall --cask teal-vpn`.

The cask downloads the same signed and notarised disk image as the download button on tealvpn.com/mac (`download.tealvpn.com/mac/TealVPN- - .dmg`, checksum pinned). The app is also published as a GitHub release.

Teal VPN is free with 500 MB a day, no card and no ads; Teal Pro adds unlimited data and every location. Made by Fxolio LLC. Support: support@tealvpn.com.
