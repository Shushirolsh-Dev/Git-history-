Homebrew tap for sipnab — a SIP & RTP capture, analysis, and security tool.

Provides prebuilt binaries for macOS on both Intel and Apple Silicon.

For Linux, use the `.deb` packages (`amd64` / `arm64`) or the static `musl` binaries from the sipnab releases.
