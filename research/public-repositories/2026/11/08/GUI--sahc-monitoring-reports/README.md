## README overview

A web application for organizing land trust monitoring photos and generating reports. Built for Southern Appalachian Highlands Conservancy (SAHC), but can be used by other organizations.

* Upload and process photos in JPEG or KMZ formats.

* Automatically extracts metadata information from the photos, if available (time the photo was taken, latitude, longitude, altitude, and direction).

* Generates PDF reports for gathering signatures.

* Free to run your own version of this application.

* This means your users will need a Google Account tied to the e-mail address they wish to login with. Note that you can create a Google Account without Gmail, so you can create Google Accounts tied to your work email addresses if desired.

If you'd like to run your own version of this application, you can do so for free on Heroku. The free version of Heroku has limits the database size, but it should be enough to hold several hundred reports (depending on the number of photos). In order to deploy to Heroku:

1. Obtain credentials for configuring Google Sign-In.

1. Create a new project at the Google API Console (this will require a Google Account for whoever is performing this deployment. If you don't already have a Google Account, you can create a Google Account without Gmail).
