## README overview

This repository contains CocoaPods podspecs for Regula iOS SDKs.

A podspec describes a specific version of a CocoaPods package, including where the SDK artifacts are downloaded from, which platforms are supported, and how the package should be integrated into an Xcode project.

This repository is intended to be used as a CocoaPods specs source. The SDK binaries and source files are not stored in this repository. Each podspec points CocoaPods to the corresponding SDK artifact.

For installation details, follow the official Regula documentation.

Regula Document Reader SDK installation guides:

Regula iOS SDK frameworks provide different scope of functionality based on the selected product and Core.

For details, see the  Document Reader SDK Core Types  and  Face SDK Core Types  in the official Regula documentation.

* For production integration, use the package and version recommended in the official Regula documentation or by Regula Support Team.

* The SDK artifacts themselves are not stored in this repository. This repository stores only CocoaPods specifications.

To submit a request to the Support Team, visit  Regula Help Center .
