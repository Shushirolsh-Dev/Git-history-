## What the project says it does

Automated Vapi Network bot featuring EVM wallet registration, SIWE authentication, on-chain identity minting, daily quest claims, multi-account management, and proxy rotation.

## README overview

It creates fresh EVM wallets, signs them in via SIWE, mints an on-chain identity, picks a random username, stores a safety word, claims the daily quest reward, and saves every account to  accounts.json , all looping automatically with proxy rotation and a live countdown between cycles.

- Ruby `3.2+` (only needed to run the downloader script)

Fill `proxy.txt` with proxies, one per line (optional, leave empty to run without proxy):

Proxies are rotated across registration attempts in round-robin order. Proxy credentials are masked in log output.

`sleep_seconds` controls how many seconds the bot waits between full registration cycles. If `config.json` is missing, the bot falls back to a default of `3600` seconds.
