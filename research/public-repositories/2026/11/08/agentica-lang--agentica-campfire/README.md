## README overview

Group chat written in Agentica: a port of 37signals' ONCE Campfire, built on Bond, EAG templates and agentica-db. The goal is parity with Rails Campfire.

Status: a skeleton with sign-in, the join link, the people page, password reset by email, and rooms with messages, on SQLite. The database is the schema of a Rails Campfire, so a database that Rails made opens as it is (see docs/configuration.md). Some tables are there before the routes that use them. What is missing, and the phases, are in docs/plan.md.

This project is licensed under Apache-2.0 (see LICENSE). It is independent. It is not affiliated with or endorsed by 37signals. Campfire is MIT licensed (copyright 37signals, LLC). Any CSS, JavaScript or images reused from it keep that copyright and license notice (`specs/fixtures/rails/LICENSE.37signals`).

Needs Agentica 0.26.1 or later on `PATH` to run the app and its tests, and a C compiler (agentica-db builds its native SQLite driver on the first run).

`CAMPFIRE_SESSION_SECRET` is required (at least 32 bytes). Behind HTTPS also set `CAMPFIRE_SECURE_COOKIES=true`. All variables are in docs/configuration.md.
