## README overview

`m1k3` installs the nightly Developer ID build of M1K3 — private, on-device AI for the Mac. It is the same signed, notarized DMG the nightly publishes at  ; the cask pins the release date as its version and the DMG's sha256, and the nightly bumps both.

The app is source-available under FSL-1.1-ALv2 — see the M1K3 repository for the licence, the brains, and the eval scoreboard. This tap holds only the install metadata.
