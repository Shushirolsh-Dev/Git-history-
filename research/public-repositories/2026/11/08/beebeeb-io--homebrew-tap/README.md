## README overview

This is the official Homebrew tap for beebeeb. It ships the `bb` command-line client — encrypt, sync, and share from your terminal; the server never sees plaintext.

Upgrade later with `brew upgrade bb`. The formula installs prebuilt binaries from the cli release page for macOS (Apple Silicon and Intel) and Linux.

Full CLI reference lives in the cli repo — or run `bb --help` after installing.

Found a vulnerability? Email **security@beebeeb.io** — see SECURITY.md.

End-to-end encrypted, zero-knowledge cloud storage — made in Europe.
