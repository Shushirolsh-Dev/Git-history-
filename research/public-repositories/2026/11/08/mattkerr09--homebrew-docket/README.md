Homebrew tap for Docket SEO: brew install --cask mattkerr09/docket/docket-seo

## README overview

Docket SEO audits a website for SEO problems on your own Mac. This tap installs the app.

That taps this repository and installs the same signed, notarised app as the download on docketseo.app/download/. It works on Apple silicon and Intel Macs, macOS 12 or later.

Docket updates itself from inside the app. This cask is kept at the current version so a fresh install starts there.

The cask only downloads the release from github.com/mattkerr09/docket-site and checks its SHA-256. Questions: support@docketseo.app.
