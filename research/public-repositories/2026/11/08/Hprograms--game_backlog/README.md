## README overview

![Deploy Status](https://game-backlog.onrender.com)

「ツミクエスト」は、増え続ける積みゲーをRPG感覚で楽しく管理・消化するWebアプリです。

「技育展2026 オンライン予選大会」に出展しました。下記リンクは発表に使用したスライド資料になります。

新しいゲームを登録する際、タイトルを一部入力するだけで、外部API（IGDB）からリアルタイムに該当ゲームの候補とパッケージ画像をサジェストします。

サジェストから選択すると、ゲームパッケージ画像や基本データ（プラットフォーム、ジャンルなど）が自動でセットされます。ユーザーは購入時期やプレイ期間、プレイ時間や自分だけの評価やメモを入力します。

裏側でDeepL APIを呼び出し、英語のあらすじデータを自動で日本語に翻訳して表示します。登録を終えると、美しいパッケージが並ぶ「自分だけのゲーム棚」がホーム画面に構築されます。

「買ったのに遊んでいない…」そんな積みゲーに対する罪悪感を、RPGのクエストをクリアするような達成感に変えたいという思いから開発しました。

単なるタスク管理ツールではなく、ゲームパッケージが並ぶ自分だけのゲーム棚を構築することで、ゲームをプレイするモチベーションを向上させる体験を目指しています。

* **ユーザー認証:** Clerkの検証済みセッションで認証し、アプリ内ユーザーごとにゲームを分離

* **ゲーム検索・自動入力:** 外部API(IGDB)と連携し、タイトル検索だけでゲームパッケージ画像や詳細データを自動取得

* **ステータス管理:** 「未プレイ」「プレイ中」「クリア済」などの進行度やプレイ時間を記録

* **画像アップロード:** Active Storageによるオリジナル画像のアップロード。パッケージ画像のないゲームに対して有効。

* **フロントエンド:** Turbo / Stimulus (Hotwire), CSS

非同期処理（Active Job）やキャッシュ機構において、従来のRedisを用いた構成から脱却し、Rails 8の最新標準である `Solid Queue` と `Solid Cache` を採用しました。これにより、RDBMSのみで完結するシンプルでモダンなインフラ構成を実現しています。

* **ゲーム検索・サジェスト表示:** `IGDB`を使ってゲーム検索、詳細情報取得を実現しました。

* **あらすじ翻訳:** `DeepL`を使って`IGDB`から取得したゲームのあらすじを日本語へ自動翻訳するようにしました。

Twitchが提供するIGDB APIを活用する際、OAuth2.0によるトークン取得・キャッシュ・API呼び出しのロジックを `IgdbApiService` クラスとしてカプセル化しました。コントローラをクリーンに保ちつつ、ユーザーが手動で画像を探す手間を省くUXを提供しています。
