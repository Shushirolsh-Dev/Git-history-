## README overview

= Canon: Semantic comparison for serialization formats

Canon provides canonicalization, pretty-printing, and semantic comparison for

serialization formats (XML, HTML, JSON, YAML). It produces standardized forms

suitable for comparison, testing, digital signatures, and human-readable output.

* **Canonicalization**: W3C XML C14N 1.1, sorted JSON/YAML keys

* **Semantic comparison**: Compare meaning, not formatting — attributes by

expanded name (namespace URI + local name), prefixes never affect results

* **Multiple interfaces**: Ruby API, CLI, RSpec matchers

* **Smart diff output**: By-line or by-object modes with syntax highlighting

* **Fast native engines, zero mandatory C deps**:

** XML on https://github.com/leptris/leptris[libleptris] (via moxml) whenever

installed — Nokogiri otherwise; HTML comparison parses through the engine's

WHATWG fragment mode. Both byte-compatible, engine

** JSON on https://github.com/leptris/yeptris[libyeptris]' strict JSON surface

(yeptris is a required gem — platform gems, zero compilation)

** YAML on yeptris (default — byte-parity with Psych, gated by the dump

corpus in the suite); Psych via `CANON_YAML_BACKEND=psych`
