## README overview

![Gem Version](https://badge.fury.io/rb/graphql_tag_pluck)

A gem for plucking GraphQL queries / mutations / fragments defined by heredocs inside `.rb` files and exporting them into a json file.

Install this gem and run the following rake task to get the exported json file containing the list of GraphQL queries / mutations / fragments.

With a sample heredoc like the following inside a `.rb` file:

will output json file like: (following json content is formatted)

- `name`: the operation / fragment name (`null` for unnamed operations)

- `source`: the normalized GraphQL document of the definition

- `type`: `query`, `mutation`, `subscription`, or `fragment`

- `file`: the file the definition was found in, relative to the current directory

- `constant`: the fully qualified constant the heredoc is assigned to (e.g. `Clients::UserClient::USER_QUERY`), or `null` when the heredoc is not assigned to a constant

Entries are keyed by definition name. Unnamed operations are keyed by their location (e.g. `"app/clients/sample_client.rb:2"`).

Definition names must be unique: any name defined more than once, even identically, raises `GraphqlTagPluck::Error` and no file is written.
