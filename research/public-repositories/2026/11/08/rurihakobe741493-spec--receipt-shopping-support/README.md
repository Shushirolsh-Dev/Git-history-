## README overview

レシパシャは、消耗品の購入を「レシートを撮るだけ」で管理できるアプリです。レシートを撮影すると消費ペースを割り出して、「そろそろ切れる」タイミングをユーザーが把握できるようにします。

**誰の、どんな課題を、どう解決するか：** ストックを"記憶と勘"で管理し続けることに疲れた人が、自分で数えることも記録することもなく、必要なものを必要な分だけ計画的に買えるようにします。

（買い物で消耗品を買うとき、前回「買った」ことは覚えていても「どの種類を買ったか」など細かいことを忘れがち）

月1〜2回ローテーションで購入しているサプリグミ3種（亜鉛・鉄・マルチビタミン）をストック数を把握せず当てずっぽうで買い、結果ストックがある亜鉛グミを二重買いし、鉄グミのストックを切らす。

もちろん対策として全部買えばストックは切らさない。しかし、それだと収納スペースが溢れて物理的なストレスになるし、うまく買えなかったこと自体にもストレスを感じてしまう。

さらに私にとってより負担なのが、ストックの状態を頭の中で抱え続け「今日は何を買えばいいか」「アレはそろそろ切れるのでは」とふと考えてしまうことです。

これらの考えが不意に湧くたびに、集中が切れてそのときやっている作業が止まってしまいます。この度重なる認知負荷が最も厄介と感じています。

「必要なものを必要な分だけ、計画的で客観的な基準にもとづいて買うサイクル」を確立し、認知負荷を減らして楽になりたい

困っているのはお金の無駄遣いや実際にストックを切らすことではなく、買うべきかどうかの判断を頭の片隅に置き続けること

買うべきもののストック数を正確に把握できておらず、買い物のたびに家に「何が・あといくつあるか」が分からない。結果、持っている種類を二重に買い、別の種類を切らす。

- なぜ①：二重買いだと収納スペースが圧迫される一方で、本当に必要なものはストックが切れるから。「必要な分だけ」買えていない。

- なぜ②：「何が・あといくつあるか」を正確に覚えていられず、当てにならない記憶に頼っているから。かといって、メモやリマインダーなどに書き出して管理するのも苦手で続かない。

- なぜ③：ストック数を常に警戒し続けること自体が日頃の負担になるから。買い物前に収納スペースへ行ってストックを数えるのも時間と手間がかかる。

**→ 本当に解決したい課題：** 日用品のストックを自分の"記憶と勘"で管理し続けることによる、終わりがなく断続的に割り込んでくる認知負荷から解放されたい。

このアプリが最も必要になるのは、自分の消耗品を自分の裁量で管理しているが、その管理を記憶や勘に頼っていて破綻している人。具体的には、開発者自身をモデルにした次の1人。
