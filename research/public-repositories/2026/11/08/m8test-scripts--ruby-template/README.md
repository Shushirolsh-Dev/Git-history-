点击 `Project` > `Sdk 右边的输入框` > `Add Sdk` > `JRuby Sdk`

找到jruby.exe的路径后点击 `Ok`, 如果是集成开发环境则在 `C:\Users\Your username\.m8test\bin\jruby\jruby.exe`

选择 `Modules` > `ruby` > `main` > `Module Sdk 右边的输入框` > `选择jruby sdk`
