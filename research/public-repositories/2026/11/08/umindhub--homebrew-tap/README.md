Homebrew casks and formulae for apps and tools by YouMindHub.

The classic Launchpad for macOS 15+, plus clipboard history, workflows and window control.

Local-first todo and project manager with Git sync, for macOS 14+.

> Both install to `/Applications/YouMindHub.app` — remove the App Store copy first

> (or use `brew install --cask --force youmindhub`).

> In-app subscription is only available in the App Store version.

Command-line tool that builds styled DMGs from a JSON config: background color or image, icon layout, Applications link, volume icon. No Finder window opens, so it also runs on CI. Signs, notarizes and staples the DMG. macOS 13+.
