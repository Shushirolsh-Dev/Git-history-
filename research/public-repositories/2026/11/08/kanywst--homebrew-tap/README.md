## README overview

kanywst's Homebrew tap. Hosts the formulae and casks for CLI and TUI tools published from this account.

Every file here is generated by an upstream release pipeline and committed from there, never edited by hand: GoReleaser for the Go tools, cargo-dist for the Rust ones (`wimsey`, `wtfi2`).

SBOMs on the GoReleaser side come from `syft`, whose default output is SPDX, not CycloneDX. Signatures are keyless Sigstore `cosign` over the checksum file, via GitHub OIDC. cosign 3 replaced the `.sig` + `.pem` pair with a single `.sigstore.json` bundle, so verification takes `--bundle`.

Every tool in the table above except `wtfi2` publishes a checksum file plus a keyless `cosign` signature over it. Verifying the signature and then the digest chains trust from the workflow identity down to the binary.

Then check the archive you downloaded against that file with `shasum -a 256 -c`.

Each upstream repo's release workflow runs on `v*` tags and commits the generated file to this repo using a `HOMEBREW_TAP_GITHUB_TOKEN` secret, a fine-grained PAT scoped to `contents: write` on this repository only. The Go tools do it through GoReleaser; `wimsey` and `wtfi2` do it through cargo-dist, which generates its formula the same way.
