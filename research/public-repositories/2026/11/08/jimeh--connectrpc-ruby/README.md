## README overview

An unofficial, experimental Ruby implementation of typed

Connect unary and native streaming RPCs. It provides a

configurable client, a Net::HTTP transport, and host-neutral servers for reusable

Ruby handlers. The optional connectrpc-rack gem

provides Rack middleware. It is not production ready.

Connect supports unary POST and opt-in safe unary GET, with identity or opt-in

gzip encoding and `application/proto` or protobuf `application/json`. The optional

Native Connect streaming uses the optional Async transport and Async/Falcon

HTTP/2 hosts. Falcon also serves Connect HTTP/1.1 server and client streaming.

The explicit Async `HTTP1Transport` supports unary, server streaming and client

streaming. See the streaming guide, including its one-second

HTTP tail policy for native Connect streaming clients.

Native gRPC supports unary, server streaming, client streaming

and bidi through the same core declarations and Async/Falcon HTTP/2 engine,

with protobuf, identity/gzip, h2c, verified TLS and mTLS. Explicit server

gRPC-Web supports unary and native server streaming within

its binary/text, host and compression limits. Connect remains the default.
