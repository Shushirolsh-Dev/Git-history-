## README overview

開始・締切を管理して、大切なタイミングを通知でお知らせする推し活特化型スケジュール管理アプリです。

FanPocketは、チケットの申し込みやグッズ販売など、忘れたくない推し活予定をまとめて管理するためのWebアプリです。

「あとでやろう」と思った予定を一度FanPocketに預けておくことで、必要なタイミングに思い出し、行動につなげられることを目指しています。

- **後回しによる機会損失の防止:** 受注販売や数量限定グッズなど、「あとで」と思っているうちに期限を過ぎてしまう買い逃し・申し込み忘れを防ぎます。

- **手入力による日付ミスの軽減:** URLからタイトルや日時候補を取得する入力補助によって、予定登録の手間や日付の入力ミスを減らします。

- **推し活予定の埋没を防止:** 仕事や日常の予定とは分けて推し活だけを管理することで、大切な開始・締切を見つけやすくします。

情報は公式XやLINE、各種サイトから収集していましたが、支払いのタイミングなどの理由から、その場ですぐに申し込んだり購入したりできず、「あとで申し込もう」「あとで買おう」と後回しにすることが多くありました。

ある時、Xのポストをきっかけに、気になっていたグッズの受注販売期間がすでに終了していたことに気づきました。

この経験から、問題は「情報を知らなかったこと」ではなく、**知った情報をあとから行動につなげられなかったこと**にあると感じました。

この「忘れてしまうもったいなさ」を減らし、大切な申し込みや購入の機会を逃さず、安心して推し活を楽しめるようにしたい。

また、一般的なToDoアプリでは、仕事や日常生活のタスクと推し活の予定が同じ場所に並びます。

私にとって推し活は、好きなものを楽しむだけでなく、日常でつらいことがあったときに元気や勇気をもらえる大切な時間でもあります。

だからこそ、その中に仕事や日常のタスクを混在させるのではなく、**「好き」な予定だけを安心して管理できる場所**を作りたいと考えました。

FanPocketでは、推し活の予定だけをまとめ、対応が完了した予定は通知対象から外すことで、

開始日時・締切日時・URL・メモなどをまとめて登録でき、開始・締切までの期間に応じた色分けによって、今確認したい予定をひと目で把握できるようにしています。

対応が完了した予定や期限を過ぎた予定は「これまでの足跡」として分けて表示し、これから対応する予定に集中できるようにしています。

また、メール・LINEそれぞれの通知タイミングは設定画面から個別にON / OFFを変更できます。

自動取得ができない場合も手入力できるようにし、取得結果に依存せず予定を登録できる設計にしています。
