## README overview

Homebrew tap for TokenTracker — a local-first AI token usage tracker for Claude Code, Codex, Cursor, Gemini, and other AI CLIs.

This tap is updated automatically by `.github/workflows/auto-update.yml`:

- Polls GitHub Releases and npm registry **hourly** for new versions

- Can also be triggered instantly via `repository_dispatch` from the main TokenTracker repo's release workflows

- Bumps `version` + `sha256` in `Casks/tokentracker.rb` and `Formula/tokentracker.rb` automatically
