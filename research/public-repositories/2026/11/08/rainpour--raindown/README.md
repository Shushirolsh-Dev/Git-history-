## README overview

Raindown is a Markdown superset for AI, APIs, Docs and humans.

The gem ships a `raindown` executable that opens a project in the terminal, and watches its Markdown files and writes back to them as they're saved, like their tables of contents, tables and endpoint responses. `raindown watch` does the watching without the terminal UI.

With `--stdin`, FILE only decides whether bare directives are allowed (by its extension), so it doesn't need to exist yet, and the TOC and tables aren't written back to it.

`raindown watch` on a directory watches each project in it, a folder with a `.raindown` folder, and the Markdown files below it, skipping hidden folders, ones like `node_modules` and `build`, and the folders your `.gitignore` files name. An Obsidian vault, a folder with an `.obsidian` folder, is left alone when it's below the folder Raindown's watching, even with a `.raindown` folder of its own, so a `raindown` on `~/dev` and the Obsidian plugin's own server don't both write back to its notes. Pointed at the vault itself, Raindown watches it as usual. The terminal UI only writes back to files in a folder's projects, or to any file saved in a folder with no projects. Each project's nodes load in a process of their own, so two projects can have nodes of the same name, and saving one of a project's nodes reloads them. Files are written back as they're saved, not all at once when watching starts.
