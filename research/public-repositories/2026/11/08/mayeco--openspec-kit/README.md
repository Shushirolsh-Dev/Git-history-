## What the project says it does

Specification-first multi-agent orchestration kit that lets AI coding agents specify, build, verify, and integrate software with OpenSpec.

## README overview

Changes are specified with OpenSpec and built by AI agents:

- Behavior lives in `openspec/specs/`. Each change is proposed, specified, built and archived under `openspec/changes/`.

- Work is queued in `config/agent_backlog.json`. `openspec-kit dispatch` plans and builds each item in an isolated worktree, and `openspec-kit merge` integrates it once the quality gates pass. Each repository declares its gates in `repos/ /repo.config.yaml`, and optionally an `env_script` that prepares its toolchain; `openspec-kit gates` runs the gates, and `openspec-kit exec repos/   ` runs any other command of a repository in its environment.

- `config/agents.yaml` lists the AI agents the project uses and, in order of preference, the ones that run each role (the next runs when one fails): `plan` (specifies each item), `build` (implements it) and `cycle` (reviews the work). With `order: random` each call starts with any agent of its role instead, and with `order: spread` with one no other running call is using, so the work spreads over the agents' quotas. The scripts read it.

- `ROADMAP.md` lists the features to build, in priority order; the cycle proposes the next ones as it goes.
