Doorkeeper is a gem (Rails engine) that makes it easy to introduce OAuth 2 provider

functionality to your Ruby on Rails or Grape application.

- OAuth 2.0 Threat Model and Security Considerations

- Proof Key for Code Exchange by OAuth Public Clients

- OAuth 2.0 Authorization Server Issuer Identification — opt-in by setting `issuer`; adds the `iss` parameter to authorization redirects returned to the client

- OAuth Client ID Metadata Documents — opt-in by setting `use_client_id_metadata_documents`; a public client identifies itself with the https URL of its metadata document instead of registering

- Keeping the Previous Access Token on Refresh
