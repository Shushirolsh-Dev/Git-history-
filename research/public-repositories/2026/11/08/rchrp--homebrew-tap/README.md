## README overview

Homebrew casks for Blame, the open-source ADE for AI coding agents.

Blame updates itself. `brew upgrade --cask --greedy blame` also works.

The cask is updated automatically by Blame's Release packages workflow when a stable version is published. Report problems on the Blame issue tracker.
