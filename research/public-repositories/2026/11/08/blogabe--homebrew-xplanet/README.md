## README overview

Xplanet Homebrew formula hosted on a personal tap to retain custom build options. See no more options in formula and no more options for default dependencies for background.

The formula builds Xplanet 1.3.1 with macOS Aqua support and backports SVN revisions r207, r208, r214, and r222–r225. The complete r214 GIF patch is pinned to Homebrew core commit b09831f, with an identical reference copy in patches/. The four r222–r225 patches remain pinned to commit c12f559; all patches have SHA-256 checksums in xplanet.rb.

The tap also includes a macOS wallpaper handoff fix. Xplanet waits for Finder's reply before removing a temporary desktop image, allowing time for first-use automation authorization. A failed or timed-out handoff reports the macOS error and retains the image in the temporary directory; repeated failures can leave multiple images there. Successful updates retain the usual temporary-file cleanup, and `-save_desktop_file` still keeps images when requested.
