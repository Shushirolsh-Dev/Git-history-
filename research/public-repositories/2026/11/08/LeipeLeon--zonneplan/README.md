## README overview

Generates an e-ink-ready image of Zonneplan's quarter-hourly dynamic electricity prices for the TRMNL display. Use the rendered PNG/BMP with the TRMNL Image display or Alias plugin.

The hourly GitHub Actions workflow publishes the latest images to GitHub Pages:

The raw gnuplot render (`hours.png`) and its data file (`hours.dat`) aren't published — each run is archived under `history/YYYY/MM/` instead.

1. **Fetch.** Scrape  , scanning the streamed Next.js chunks (`self.__next_f.push([...])`) for the electricity block's price arrays. The 15-minute `quarters` array is preferred; the 60-minute `hours` array is the backstop.

2. **Fallback.** If neither array turns up, fall back to the EnergyZero public API (`https://api.energyzero.nl/v1/energyprices`), which only serves hourly prices. Pricing profile (`low` / `normal` / `high`) is then classified by quartile bucketing across the day's prices.

3. **Tabulate.** Write a gnuplot data file with the tax-included total price, the profile color and a label on the window's cheapest and priciest entry. Past entries (older than ~1h) are greyed out; anything older than 4h is dropped. Quarter-hour rows only carry an x-axis label on the hour.
