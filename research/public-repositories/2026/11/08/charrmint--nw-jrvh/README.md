## README overview

OneKare is an AI-assisted daycare application platform. Parents create one profile, and OneKare prepares and submits supported daycare forms and email waitlist requests after parent review and approval.

See the architecture and implementation plan for the shared automation engine, reusable platform adapters, database-backed provider configuration and delivery milestones.

The current parent-facing work includes a fixed MVP upfront question contract, a central general application per child, and Settings for encrypted YMCA portal credentials. After pulling these changes, run `bin/rails db:migrate` against your development database before opening those pages. The daycare-specific review and submission flows are the next development phase.

For assigning team work, use the frontend/backend implementation plan. It defines matching screens, routes, models, service classes, worker contracts, task dependencies and acceptance criteria.

The initial scenarios are YWCA public forms, YMCA authenticated applications using securely stored provider credentials, and Parkcrest Child Care Society email-only school-age waitlist requests. Parkcrest ends at **Waitlist request sent**; inbox monitoring and subsequent enrollment are outside the MVP.
