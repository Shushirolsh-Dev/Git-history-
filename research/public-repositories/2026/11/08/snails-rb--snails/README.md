## README overview

snails is a framework for building web apps that compile to a single native binary. You write ordinary Ruby — routes, controllers, models, forms — and snails turns it into one binary that boots fast and runs anywhere a binary runs. There is no runtime to install on the server, no asset pipeline, and no view layer: your app answers with JSON.

The project is split into parts: the API-only, Rails-like runtime for Spinel (`runtime/`), the CLI (`cli/`), and the project scaffolder (`scaffold/`). A consuming app vendors the runtime as `snails-core/` and pins the revision in `pins.toml`.

Status: alpha. The public API can change between 0.x releases.

The first command that needs the toolchain assembles the pinned compiler. See Getting Started for the full first-project flow.

The manual is the product documentation. It lives in `manual/` and is written for people building an app.
