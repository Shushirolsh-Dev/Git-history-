## What the project says it does

Fledge packages software written in Ruby so that people can run it without installing Ruby. Your users download one file, unpack it wherever they like, and run it. If your app has windows, Fledge also builds an installer for each system.

**Fledge** turns a Ruby program you already run into an app that people without Ruby can download and run. It copies your program, your project, and the gems your `Gemfile.lock` locks into a Ruby that runs from any folder, adds a launcher that starts your program as `bundle exec` would, and archives the result. Your users unpack one file and run it. They install nothing, and never learn what Ruby is.

Fledge is for Ruby developers with a working program, such as a command-line tool, a terminal app, a game, or a windowed app, who want to give it to people who have never heard of Ruby. Lota's `lota fuse` builds its games with Fledge.
