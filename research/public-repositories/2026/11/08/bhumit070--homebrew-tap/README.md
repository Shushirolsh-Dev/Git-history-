PostgreSQL, MySQL, SQLite, Redis and MongoDB.

Tabula isn't notarized by Apple yet, so macOS blocks the first launch. Open

Tabula once, then go to **System Settings → Privacy & Security** and click

**Open Anyway**. Or clear the quarantine flag yourself:

`Casks/tabula.rb` is generated by the release workflow in

(`packaging/homebrew/cask.sh`); change it there, not here.
