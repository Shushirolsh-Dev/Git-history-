## What the project says it does

Homebrew formulae for 23made's tools, including the 23artifacts command line (23a).

## README overview

`23a`, the command line for 23artifacts: sign in through your browser, publish a folder or a file, and get its address back.

It installs the command as `23a` and as `23artifacts`, on macOS and Linux, Apple silicon, Intel and ARM. The same command is on npm as `23artifacts`. Documentation is at https://23artifacts.com/docs.

Each release's files are attached to this repository's releases, and the formula is updated by 23made's release process.
