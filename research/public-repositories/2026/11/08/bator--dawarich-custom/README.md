## README overview

Custom code on top of upstream Dawarich 1.22.0.

It matches recorded location history against Hungarian public-transport timetables (GTFS), and

`restore_custom.py` puts it back after every community-script upgrade.

Also: **Settings** (opt-in, feeds, minimum confidence, rematch the whole history), transit layers on `/map/v2`,

**Frequent routes** (the middle line of walks and rides made many times, a map layer, and snapping new tracks onto it;

docs/corridors.md), **Directions** on `/map/v2` by car, bike, on foot and by public transport through a

self-hosted Dawarich Atlas, and `track_pick`, a daily Discord pick of which user's track to copy onto the target account.

Dawarich container, one command on the node (docs/proxmox.md):

- **Docker**: an image built on top of the official Dawarich image

(`freikin/dawarich` on Docker Hub, built from

Freika/dawarich), with the Discord bot as its own container

A community-script upgrade replaces `/opt/dawarich/app` wholesale. The restore merges our edits into the new

upstream files instead of overwriting them, and stops on anything it cannot merge cleanly.

State: `/var/lib/dawarich-custom/` (`state.json`, backups, `conflicts/ /`).
