## README overview

> A Rust CLI that drives LLM agents through a PRD's tasks in a loop — and **independently verifies** every acceptance criterion instead of trusting the agent's self-report.

This is the official Homebrew tap for Zurdo. The formula installs a licensed pre-built binary from the public zurdo-dist releases — no toolchain required. Zurdo is proprietary, closed-source software.

Shipped targets: macOS Apple Silicon, and Linux x86_64 / aarch64 via Homebrew on Linux. (Intel macOS is not pre-built yet.)

> **Upgrading from a pre-1.0 install?** Older versions were tapped with

> `brew tap ElOrlis/zurdo https://github.com/ElOrlis/zurdo` — pointing at the

> source repo, which is now private and no longer carries the formula. Re-tap

Zurdo shells out to an agent CLI for the executor role — install and authenticate at least one of `claude`, `codex`, or `copilot`. See the installation guide for details, including release-tarball installs with checksum verification.

Full documentation lives at **zurdo.numeron.ai**:

- How it works — the verification loop, state model, evidence integrity, crash recovery

- Usage — everyday workflows, run output, CI integration, troubleshooting
