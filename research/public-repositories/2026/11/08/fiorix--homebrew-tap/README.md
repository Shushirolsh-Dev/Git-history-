## README overview

Homebrew loads packages from taps outside its own catalogue only once you trust them, so trust each package before installing it.

minitile is a small tiling window manager for macOS: pages run horizontally, workspaces stack vertically, and familiar shortcuts move between them. It needs macOS 26 or later on Apple silicon.

The cask installs `Minitile.app` and links the `mntl` command line tool. Upgrade with `brew upgrade --cask minitile`; `brew uninstall --zap --cask minitile` also removes its configuration and state. Before the first launch, give every display a second desktop in Mission Control; see Getting started.

chan is a supercharged terminal emulator, free and open source. Apple silicon macOS only. Install the desktop app, `Chan.app` from the signed and notarized release DMG, or the headless CLI, the released `chan` binary with its `cs` symlink; one or the other, not both, since the app provides the same `chan` and `cs` commands through shims in `~/.local/bin` that it maintains itself.

The app updates itself; the cask declares `auto_updates`, so `brew upgrade` skips it unless given `--greedy`. The CLI updates through `brew upgrade chan`; prefer that over `chan upgrade` so Homebrew's recorded version stays correct. Both definitions are rendered from templates in fiorix/chan (`packaging/distros/homebrew/`) and pushed here by its `publish-downstream` workflow at every GA release; the tap's update workflow leaves these two files alone. Do not edit them by hand.
