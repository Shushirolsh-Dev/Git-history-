## README overview

Health, inventory, vulnerabilities, Docker and SSH keys — agentless, read-only, over SSH.

Elio watches a fleet of Debian and Ubuntu servers from one place: which ones are healthy, what runs on them, which packages are vulnerable and how to fix them, who has an SSH key on them. Nothing to install on the servers: Elio logs in with its own SSH key and runs a short list of **read-only commands**, all written in one file you can review — `config/ssh_commands.yml`.

> **Beta.** Elio is young (`v0.4.0-beta`). It is used on real servers, but expect rough edges, and read the known limits.

The interface is in **English and French**. Each user picks a language in *My account*; otherwise Elio follows the browser, then the default language of the installation (*Settings → General*). Notification channels and invitations have their own language. Adding a language is adding a folder of translations: see CONTRIBUTING.md.

Open   and create the first account: it is the administrator. Then, in *Settings → General*, generate Elio's SSH key, add it to a server's `~/.ssh/authorized_keys`, and add the server.

**Keep `.env` safe**: without its keys, the encrypted data (Elio's SSH key, API keys, webhooks) cannot be read back.
