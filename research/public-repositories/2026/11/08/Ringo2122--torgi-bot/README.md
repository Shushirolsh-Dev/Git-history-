## README overview

Telegram-бот: следит за новыми лотами недвижимости и транспорта на **e-auction.by** (БелЮрОбеспечение)

**ipmtorgi.by** (ИПМ-Торги), **beltorgi.by** (Белреализация) и **konfiskat.by** (Торговый дом «Восточный»).

cpo.by (ЦПО) с 25.09.2026 не читаем: это рекламная витрина торгов ИПМ, лоты те же. По каждому новому лоту присылает название, фотографию, стартовую цену

Работает автономно на сервере, Claude для этого не нужен.

**Дубли.** Лот с тем же названием и стартовой ценой, уже встреченный на другой площадке, бот не присылает повторно (подписи `sig|…` в памяти).

На konfiskat.by в списке только дата аукциона: заявки по извещениям — до 12:00 накануне.

Цена, дата и фото берутся прямо из списка лотов. Исключение — beltorgi.by: в списке

(`/ /?limit=80&page=N`, с 25.09.2026; раньше — POST `/assets/category.php`) вместо срока заявок

показан обратный отсчёт. Поэтому за точным сроком бот заходит в каждый **новый** лот beltorgi.

Каждый раздел читается целиком, все страницы с активными лотами: около 50 запросов

и две-три минуты на цикл. Читать только первую страницу нельзя — ИПМ-Торги

сортируют по сроку приёма заявок, и старые лоты «въезжают» на первую страницу,
