## README overview

Homebrew tap for kagan, a desktop app for coding with agents.

The cask installs `kagan.app` and puts `kg` on your `PATH`. It needs an Apple silicon Mac.

The kagan Release workflow updates `Casks/kagan.rb` after each release. Do not edit the version or checksum by hand.
